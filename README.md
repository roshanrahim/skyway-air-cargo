# SKYWAY Air Cargo & Courier Services — Website

**Live site:** https://roshanrahim.github.io/skyway-air-cargo/

Business website for SKYWAY Air Cargo and Courier Services — authorised agent of
**Aramex Delivery Unlimited** — Alangad, Ernakulam, Kerala. Open 24×7.

## Stack
Pure static HTML + CSS + vanilla JS. No build step, no backend. Hosted free on GitHub Pages.

## Pages
Home · About Us · Services · Rates & Quote (calculator) · Tracking · Destinations ·
Restricted Items · FAQ · Blog & Advisories · Contact

## Quick Config
All site-wide contact details live at the top of [`js/main.js`](js/main.js):
`SKYWAY_PHONE`, `SKYWAY_WHATSAPP`, and the `RATES` tariff table for the calculator.

## Deploy
```bash
git add . && git commit -m "update" && git push   # live in ~1 minute
```
